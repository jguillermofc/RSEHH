Each comparison table shows the mean and standard deviation for a given indicator, considering the whole test instances (i.e., each one defines a subset selection instance). Here we show the full set of comparative tables concerning Application Experiment in Section 6.3 of the main manuscript. Each table shows the IGD or IGD+-based comparison, using a reference point set constructed by means of RHH, RSE, RSG, SLD, UDH, and RND strategies, of the nine selected MOEAs: MOEA-UD, PREA, AdaW, MaOEAIGD, tDEACPBI, MOEA/D, MOMBI-II, NSGA-II, and SPEA2. Each table shows in boldface the MOEA with the minimum IGD/IGD+ mean value per instance. Moreover, a superindex shows the ranking in the comparison assigned to each MOEA. These tables, and especifically the ranking values, are the baseline data for the approximation of preferences of IGD/IGD+ described in Section 6.3 of the manuscript.
